# Bounded autonomous stewardship

The Company declares an `autonomous_safe` stewardship profile while runtime control remains disabled by default. “YOLO” is only a conversational alias for an authenticated owner request to enable this profile until an explicit expiry; words in a prompt never grant authority.

Lily may propose. The declared operator identity independently approves, the GitHub workflow evaluates and merges an unchanged checked head, the reconciler applies an exact approved plan, and the observer records outcome evidence. Authority/governance, secrets, destructive actions, spending limits, and autonomy-policy changes remain protected. Validation, independent review, unchanged-head, and successful-check gates are mandatory in every enabled interval.

The scheduler has no Provider credentials and can only wake declared durable company work through a server-bound operation identity. Disabling, pausing, expiry, exhausted limits, denial, or protected work stops scheduling. After a governed merge, reconciliation and observation remain required before Lily can report completion.

Production enablement, plan approval, and apply are external effects and require exact attributable owner decisions. This declaration and its tests do not claim that the profile is currently enabled or that a pending production plan has been applied.
